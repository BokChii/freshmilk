주요 변경 사항은 아래와 같습니다.
문제풀이 응답 구조 변경
문제 조회/세션 시작 응답에서 정답은 내려가지 않습니다.
프런트는 question.type, choices, resource, payload를 보고 화면을 렌더링하면 됩니다.
정답은 백엔드의 questions.answer_json에 저장되고, 서버에서 채점합니다.
답안 제출 구조 정리
프런트는 answer 객체로 사용자 답안을 제출하면 됩니다.
예: { "questionId": 4, "answer": { "choiceIds": ["B"] } }
제출 후 백엔드가 correct, correctAnswer, explanation, reward를 반환합니다.
연속 학습 응답 보강
홈 응답의 continueLearning에 진행 중 attempt, resume 여부, 다음 학습 세션 정보가 추가됐습니다.
프런트에서 “이어서 학습하기” 버튼 구성에 사용할 수 있습니다.
복습 API 추가/정리
GET /reviews/today
POST /reviews/{reviewSetId}/answers
POST /reviews/{reviewSetId}/complete
복습 문제는 기존 오답/최근 학습 문제 기반으로 구성됩니다.
지폐 재화 API 추가
GET /wallet
POST /wallet/bills/grant
POST /wallet/bills/spend
실제 결제 연동은 아직 포함하지 않고, MVP에서는 지폐 잔액 조회/지급/차감까지만 구현했습니다. </aside>
