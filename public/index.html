Slack Commands

  • /daily-summary - 작업자별 스크럼과 AI 요약 생성
  • /record - 회의/고객사/업무 메모 구조화 저장
  • /ask - 저장된 기록에 질문
  • /action - 저장된 기록에서 액션 아이템 추출
  • /weekly - 주간 리포트 생성
